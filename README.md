# 艾宾浩斯日程表 · README（基础篇）

依据**艾宾浩斯遗忘曲线**自动排复习计划的 Windows 桌面小程序：
**纯 Python + Tkinter，零第三方依赖，双击即用**。数据只存一个 JSON 文件，可随时备份/迁移。

首次学习后按 **+1 / +4 / +14 / +28 天** 自动生成 4 次复习。例：
「2026-01-01 学习高数-拉格朗日」→ 自动安排 **1/2、1/5、1/15、1/29** 复习。

> 想深入源码、算法与工程细节？请看 **[readme_professional.md](./readme_professional.md)**（源码剖析·进阶篇）。

---

## 一、快速开始

前提：装了 **Python 3**（安装时勾选 *Add Python to PATH*）。Tkinter 是自带库，**不用装任何东西**。

1. 双击 **`启动艾宾浩斯.vbs`** 启动（推荐：无黑窗口、不受命令行中文编码影响）。
2. 想要桌面图标：双击一次 **`创建桌面快捷方式.vbs`**。
3. 报错/没反应：双击 **`诊断_出错看这里.bat`**，它会保留窗口显示 `Traceback`。

也可直接命令行：`python app.py`。所有界面/逻辑/算法都在 `app.py` + `models.py` 里。

## 二、界面速览（三个页面 + 底部导航）

```
┌──────────────────────────────┐
│ 学习表 | 还剩N项提示语 |  🔍  │   ← 顶部青绿栏(右上角=搜索图标)
├──────────────────────────────┤
│ 卡片列表（复习卡 + 学习计划） │   ← 中间内容区
│ ……                            │
│ 今日完成 [███████░░░] 71%    │   ← 首页进度条
├──────────────────────────────┤
│  学习表   今日所学   完成     │   ← 底部导航
└──────────────────────────────┘
```

- **学习表（首页）**：展示"还没做完"的卡片，到期/过期的用彩色边框标在最前。
- **今日所学（录入页）**：选类型 + 录入内容 + 日期，自动分类排日程。
- **完成（清单页）**：所有打钩完成的记录，取消勾选即可还原。
- **搜索（右上角放大镜图标）**：独立小窗口，可搜索**全部任务**（未完成的复习/学习计划、已完成的复习/学习记录都能搜到），点结果卡片进入同一个详情弹窗。

### 卡片颜色一眼看懂

| 卡片 | 什么时候出现 | 边框 |
| --- | --- | --- |
| 复习卡（第 N 次复习） | 一条任务每次未完成的复习展开一张 | **今日到期/过期 = 红色**；未来 = 灰色 |
| 学习计划卡（"学习计划" / "学习计划（不复习）"） | 选**今天或未来**日期创建的任务，完成学习前只有这一张 | **到期/逾期 = 绿色**（醒目提醒去完成）；未来 = 灰色 |

> 红色/绿色边框就是为了"显眼"：一眼看出今天要完成哪些。
> 两种学习计划的区别：**需复习**的完成学习后自动排 4 次复习；**不复习**的完成后不产生任何复习。

## 三、每天怎么用（操作速览）

1. **录入**：进「今日所学」，先选类型，再输入名称、选日期，回车即添加。
   - 三种类型（互斥，默认第一种）：**今日所学（创建复习计划）** / **学习计划（需复习）** / **学习计划（不复习）**；
   - 「今日所学」+ 日期为**今天或过去** → 复习日程（按 +1/+4/+14/+28 排 4 次复习）；
   - 「今日所学」+ 日期为**未来** → 自动改为学习计划，提示"日期为未来，已自动改为学习计划"；
   - 「学习计划」+ 日期为**过去** → 自动改为复习计划，提示"日期已过去，已自动改为复习计划"（两种学习计划都一样）；
   - 「学习计划」+ 日期为**今天或未来** → 绿卡（应完成日期 = 所选日期）；需复习的完成学习后自动排 4 次复习，**不复习的完成后不产生任何复习**。
2. **打卡**：学习表卡片右侧方框打钩 = 完成这一次复习 / 完成这次学习。
   - "需复习"绿卡勾选"完成学习"后，自动以**完成当天**为基准生成 4 次复习；"不复习"绿卡勾选后直接结束，无复习。
3. **完成清单**：取消勾选 = 还原（复习按规则重排回学习表；学习计划整条还原回绿卡；不复习的学习计划还原时不会弹确认框）。
4. **详情**：点卡片弹出详情——复习任务可看 4 次复习、逐次勾选/还原、逐次**改期**、改任务**名称**、**删除**任务；绿卡的"应完成学习"行自带勾选框，并可改期应完成日期（"不复习"绿卡详情只有这一行，没有任何复习行）。
   - 详情里还有 **"复习方式"** 选项：**需复习 ⇄ 不复习** 随时切换（未完成学习时直接切换；已完成学习时会先确认——改成"需复习"按完成学习日重建 4 次复习，改成"不复习"则删除复习计划）。
   - 若之前不小心把"不复习的学习计划"建成了复习日程，也可以在这里把它切换成 **"不复习的学习计划"**（会先确认，删除其 4 次复习计划）。
5. **进度条**（学习表底部）：显示"今日完成 X%"：今日到期且完成的 ÷ 今日到期总数；今天没有待办时显示 100%。
6. **搜索**：点右上角放大镜图标打开独立搜索窗口；输入关键词后按**回车**或点右侧**搜索**按钮即可。
   - 匹配规则：大小写不敏感的**子串**匹配（任务名"1234"输入"4"也能搜到），关键词自动去首尾空格；
   - 结果按任务**去重**（每个任务一张卡，只显示任务名称），点卡片打开与学习表相同的详情弹窗；
   - 搜索过程中结果区会显示一个旋转的圆圈动画，出结果后自动消失；支持滚轮和右侧滚动条；
   - 不输入关键词时，结果区居中提示"**请输入关键词**"（不会列出全部任务）；关掉搜索窗口即退出搜索，不影响主程序。

## 四、提醒 & 后台常驻

- **系统通知**：右下角弹「问候语 + 还剩 N 项」；常驻时在 **0 / 7 / 9 / 13 / 17 / 20 点**各推一次。
- **N 的口径**：今天到期的**复习** + 今天到期的**学习计划**合在一起算（如 3 复习 + 2 学习 → "还剩 5 项"）。
- **改文案**：所有提示语在 **`phrases/`** 的 txt 里，一行一句，`#` 注释；任务提示里的 `*` 会被替换成剩余数。保存即生效，无需改代码。
- **托盘常驻**：点窗口 X 不会退出，缩到右下角托盘继续后台提醒；悬停显示任务数，双击打开，右键退出。
- **开机自启**：双击一次 **`开启开机提醒.vbs`**（启动即缩托盘 + 先弹一条今日任务）；**`关闭开机提醒.vbs`** 取消自启并停掉后台。
- **只开一份**：程序有单实例保护，重复双击只会把已有窗口唤起，不会开两个、发两条通知。

## 六、实现入门：它是怎么运转的、数值怎么算

### 6.1 最小结构

```
Series（一条学习内容：2.1 随机变量）
├─ kind      = "review" 复习日程 / "plan" 学习计划(需复习) / "simple_plan" 学习计划(不复习)
├─ learn_date= 首次学习日期 / 应完成日期
├─ done_learn、done_learn_date      （plan / simple_plan 是否已完成学习）
└─ reviews   = [Review(第1次), Review(第2次), Review(第3次), Review(第4次)]
    每个 Review: n / date(计划日) / done / done_date(实际完成日)
    (simple_plan 的 reviews 始终为空: 完成学习也不生成复习)
```

### 6.2 关键数值怎么算（核心公式）

| 数值 | 算法 |
| --- | --- |
| 复习日期 | 偏移表 `OFFSETS=[1,4,14,28]`：第 i 次复习日 = **学习日期 + OFFSETS[i]**（如 1/1 学 → 1/2、1/5、1/15、1/29） |
| 绿卡完成学习后的复习 | 仅"需复习"类型：以**完成学习当天**为基准生成 完成日 + 1/4/14/28；"不复习"类型不生成 |
| 今日待办 N | `未完成复习且日期 ≤ 今天` 的数量 + `未完成学习计划(需复习/不复习都算)且应完成日期 ≤ 今天` 的数量 |
| 自动后移 | 若某条任务**最早的未完成复习日 < 今天**，把该条**所有未完成复习整体后移** `(今天 − 最早日)` 天，使最早那一次正好落今天；已完成的固定不动。程序**每次启动**和**跨天**时各跑一次 |
| 拖欠天数 | 绿卡上 `今天 − 应完成日期`（红色提示"拖欠 N 天"；日期本身程序不改） |
| 今日完成进度 | 已完成 ÷ 待办总数；今天无任何待办 → 显示 100% |
| 还原（取消勾选） | 第 i 次还原会**级联**还原 i~4；并按到期情况安排：当天保持、过期改到今天并整体平移、未来不动 |
| 改期 | 复习行改期：只改该次并把其后**未完成**的按相同天数平移（已完成不动）；任务"学习日期"改期另有规则（见进阶文档 4.4） |
| 通知时刻 | 整点 0/7/9/13/17/20；问候语按 6 个时间段（0-7/7-9/9-13/13-17/17-20/20-24）随机 |
| 顶部提示语 | 剩余数**变化时**才重新随机换一句（避免刷新跳字） |

### 6.3 一个完整例子

- 9月5日录「连续型随机变量」，日期选今天 → 复习日程：第1~4次复习计划日 = 9/6、9/9、9/19、10/3。
- 若 9/6 忘了打卡，9/8 才打开程序：自动后移 2 天 → 计划变 9/8、9/11、9/21、10/5（最早未完成的正好落到今天）。
- 另在 9/5 录「9月10日要学 CSAPP 3.10」→ 因日期在未来，生成绿卡（应完成 9/10）。9/10 当天它是绿色"今日到期"并计入"还剩 N 项"；这天你学了它并勾选完成 → 自动生成 4 次复习（9/11、9/14、9/24、10/8）。
- 若录「读完《xxx》」并选**学习计划（不复习）**、日期选今天 → 当天它就是绿色"今日到期"并计入"还剩 N 项"；勾选完成后直接进"完成"清单，**不会产生任何复习**。
- 想找旧任务：点右上角放大镜，输入"CSAPP"回车 → 结果只列任务名，点一下就能打开它的详情/改期。
