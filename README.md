# 艾宾浩斯日程表 · README（使用篇）

依据**艾宾浩斯遗忘曲线**自动排复习计划的 Windows 桌面小程序：
**纯 Python + Tkinter，零第三方依赖，双击即用**。数据只存一个 JSON 文件，可随时备份/迁移。

首次学习后按 **+1 / +4 / +14 / +28 天** 自动生成 4 次复习。例：
「2026-01-01 学习高数-拉格朗日」→ 自动安排 **1/2、1/5、1/15、1/29** 复习。

> 想深入源码、算法与工程细节？请看 **[readme_professional.md](./readme_professional.md)**（源码剖析·进阶篇）。

---

## 一、快速开始

前提：装了 **Python 3**（安装时勾选 *Add Python to PATH*）。Tkinter 是自带库，**不用装任何东西**。

1. 双击 **`启动艾宾浩斯.vbs`** 启动（推荐：无黑窗口、不受命令行中文编码影响）。
2. 想要桌面图标：双击一次 **`创建桌面快捷方式.vbs`**。
3. 报错/没反应：双击 **`诊断_出错看这里.bat`**，它会保留窗口显示 `Traceback`。

也可直接命令行：`python app.py`。界面/逻辑/算法都在 `app.py` + `models.py` 里。

## 二、界面速览（三个页面 + 底部导航）

```
┌──────────────────────────────┐
│ 学习表 | 还剩N项提示语 | ⚙ 🔍 │   ← 顶部青绿栏(右起: 搜索 / 齿轮设置)
├──────────────────────────────┤
│ 今日待完成（到期/逾期卡片）   │   ← 中间内容区: 第一段直接展示
│ ▸ 后续任务 · N 项（点击展开） │   ← 第二段默认折叠, 点了才建卡片
│ 今日完成 [███████░░░] 71%    │   ← 首页进度条
├──────────────────────────────┤
│  学习表   今日所学   完成     │   ← 底部导航
└──────────────────────────────┘
```

- **学习表（首页）**：展示"还没做完"的卡片，并**分两段**：**今日待完成**（到期/逾期，直接展示，彩色边框标在最前）与**后续任务**（日期在未来的卡片，默认折叠成一行，点击才展开渲染）。任务多时不会一次建出所有卡片，首屏更快。
- **今日所学（录入页）**：选类型 + 录入内容 + 日期，回车进详情录入，确认后创建。
- **完成（清单页）**：打钩完成的记录，同样**分两段**：**最近 3 天完成**直接展示，**更早完成**默认折叠成一行、点击才展开；取消勾选即可还原。
- **搜索（右上角放大镜图标）**：独立小窗口，顶部选择框可切换**按名称**（默认）或**按日期**搜索；按名称可搜**全部任务**（未完成的复习/学习计划、已完成的复习/学习记录都能搜到），按日期用内嵌月历挑一天、分「该日创建 / 该日完成」两段查看，点结果卡片都进入同一个详情弹窗。

> **卡片标题永远只有一行**：标题太长时超出部分显示成中文省略号"…"，不会把卡片撑变形；
> 窗口拉宽/变窄时会重新计算，能多显示几个字就多显示几个字。想看完整标题就点开卡片——
> 详情窗顶部是**完整标题**，太长时会出现横向滚动条（鼠标放在标题上滚轮左右滚）。

> **卡片右侧的「复制」小图标**（两个重叠的小方框，纯 Tkinter 画的，不依赖图片）：点一下就把这张卡片的
> **任务全部信息**按"每条一行"的纯文本复制到剪贴板（标题 / 详情 / 类型 / 学习日期或应完成日期 /
> 复习日期 / 完成情况 / 创建时间，详情为空时写"无"）；同时窗口最上方会浮出一个白底圆角
> 「**已复制**」提示框——前 1 秒清晰、之后 1 秒平滑淡出，**3 秒后自动消失**。
> 连着点只会重新计时，不会叠一堆框，也不影响其它操作。
>
> 复制出来的样子（复习日程 / 学习计划各一例）：
>
> ```text
> 标题：C++ 基础入门了解
> 详情：无
> 类型：复习日程
> 学习日期：2026-01-01
> 复习日期：2026-01-02、2026-01-05、2026-01-15、2026-01-29
> 完成情况：未完成（0/4 次复习）
> 创建时间：2026-01-01 09:30
> ```
>
> ```text
> 标题：CSAPP 3.10
> 详情：无
> 类型：学习计划（需复习）
> 应完成日期：2026-01-10
> 复习日期：无（完成学习后自动生成 4 次复习）
> 完成情况：未完成学习
> 创建时间：2026-01-01 09:31
> ```

### 卡片颜色一眼看懂

| 卡片 | 什么时候出现 | 边框 |
| --- | --- | --- |
| 复习卡（第 N 次复习） | 一条任务每次未完成的复习展开一张 | **今日到期/过期 = 红色**；未来 = 灰色 |
| 学习计划卡（"学习计划" / "学习计划（不复习）"） | 选**今天或未来**日期创建的任务，完成学习前只有这一张 | **到期/逾期 = 绿色**（醒目提醒去完成）；未来 = 灰色 |

> 红色/绿色边框就是为了"显眼"：一眼看出今天要完成哪些。
> 两种学习计划的区别：**需复习**的完成学习后自动排 4 次复习；**不复习**的完成后不产生任何复习。

## 三、每天怎么用（操作速览）

1. **录入**：进「今日所学」，先选类型，再输入名称、选日期，**回车**——第一次回车不会马上建好，而是弹出「详情」编辑窗（知识点/特殊方法/备注随便写，可多行分段）；在详情窗里再按一次**回车**或点**确认**才真正创建。
   - 不想写详情就直接按回车/点确认，详情记为空，界面统一显示"**无**"；
   - 在详情窗里点**取消 / 窗口 X / Esc** 会问一句"**是否保留刚刚创建的任务？**"：选"是"=照常创建（详情为"无"），选"否"=连标题一起丢弃；
   - 详情编辑窗的键盘规则：**Enter 保存并创建**、**Shift+Enter 换行**、**Ctrl+S 暂存但不结束**（中文输入法选字时的回车会尽量被忽略，不会误提交）；
   - 任务名称不能为空，空名称不会创建；
   - 三种类型（互斥，默认第一种）：**今日所学（创建复习计划）** / **学习计划（需复习）** / **学习计划（不复习）**；
   - 「今日所学」+ 日期为**今天或过去** → 复习日程（按 +1/+4/+14/+28 排 4 次复习）；
   - 「今日所学」+ 日期为**未来** → 自动改为学习计划，提示"日期为未来，已自动改为学习计划"；
   - 「学习计划」+ 日期为**过去** → 自动改为复习计划，提示"日期已过去，已自动改为复习计划"（两种学习计划都一样）；
   - 「学习计划」+ 日期为**今天或未来** → 绿卡（应完成日期 = 所选日期）；需复习的完成学习后自动排 4 次复习，**不复习的完成后不产生任何复习**。
2. **打卡**：学习表卡片右侧方框打钩 = 完成这一次复习 / 完成这次学习。
   - "需复习"绿卡勾选"完成学习"后，自动以**完成当天**为基准生成 4 次复习；"不复习"绿卡勾选后直接结束，无复习。
   - 学习表按日期分两段：**今日待完成**（日期 ≤ 今天，含逾期）直接展示；**后续任务**（日期 > 今天）默认只显示一行「▸ 后续任务 · N 项 点击展开」，点它才建卡片、再点收起。
3. **完成清单**：取消勾选 = 还原（复习按规则重排回学习表；学习计划整条还原回绿卡；不复习的学习计划还原时不会弹确认框）。
   - 完成清单也分两段：**最近 3 天完成**（含今天与往前第 3 天，天数见 `COMPLETED_RECENT_DAYS`）直接展示；**更早完成**默认折叠成一行，点击才展开渲染。
4. **详情**：点卡片弹出详情窗，从上到下是：**完整标题**（单行不换行，太长出现横向滚动条，鼠标放标题上滚轮左右滚）→ **任务详情**（方框展示，太长出现竖向滚动条，鼠标放详情上滚轮上下滚；两处各滚各的互不影响）→ 原来的复习行与操作按钮。
   - **详情默认只读**，点右上角「**编辑详情**」才能改。编辑时：**Enter 保存并退出编辑**、**Shift+Enter 换行**、**Ctrl+S 暂存但不退出**（方便接着写）；正在编辑时点窗口 X 会先问"要不要保存"；
   - 原来没有详情（显示"无"）的任务，点编辑后输入框是空的；也可以把已有详情**清空**，清空后照样显示"无"（存的是空值，不会真的存一个"无"字）；旧版本的任务没有详情字段，一律当空详情处理；
   - 详情挂在**整条任务**上（三种类型都有、一条任务共用一份），**卡片列表里不显示详情**，只在详情窗里看/改；改详情不用刷新列表，改名字会同步刷新上方完整标题和背后卡片；
   - 复习任务可看 4 次复习、逐次勾选/还原、逐次**改期**、改任务**名称**、**删除**任务；绿卡的"应完成学习"行自带勾选框，并可改期应完成日期（"不复习"绿卡详情只有这一行，没有任何复习行）。
   - 「**修改名称**」的输入窗会按当前名称的长度**自动加宽**（360~560px），常见长度的名称能整条看清，不用来回挪光标；名称特别长时窗口加宽到上限为止，输入框里可以左右滚动查看。
   - 详情里还有 **"复习方式"** 选项：**需复习 ⇄ 不复习** 随时切换（未完成学习时直接切换；已完成学习时会先确认——改成"需复习"按完成学习日重建 4 次复习，改成"不复习"则删除复习计划）。
   - 若之前不小心把"不复习的学习计划"建成了复习日程，也可以在这里把它切换成 **"不复习的学习计划"**（会先确认，删除其 4 次复习计划）。
5. **进度条**（学习表底部）：显示"今日完成 X%"：今日到期且完成的 ÷ 今日到期总数；今天没有待办时显示 100%。
6. **搜索**：点右上角放大镜图标打开独立搜索窗口。窗口顶部是仿照「今日所学」的选择框，二选一：**按名称搜索**（默认）与**按日期搜索**。
   - **按名称搜索**：输入关键词后按**回车**或点右侧**搜索**按钮即可。
     - 匹配规则：大小写不敏感的**子串**匹配（任务名"1234"输入"4"也能搜到），关键词自动去首尾空格；
     - 结果按任务**去重**（每个任务一张卡，只显示任务名称），点卡片打开与学习表相同的详情弹窗；
     - 搜索过程中结果区会显示一个旋转的圆圈动画，出结果后自动消失；支持滚轮和右侧滚动条；
     - 不输入关键词时，结果区居中提示"**请输入关键词**"（不会列出全部任务）。
   - **按日期搜索**：选后窗口内**内嵌一个月历**（不另开窗口），按月展示当月所有日期，左右箭头翻月。
     - 日期数字统一**黑色**；**有改动**（当天创建过任务，或完成过某次复习 / 完成学习）的是**淡绿色方块**，没有改动的是**白色方块**；
     - **今天**的日期用**黑色加粗方框**；**当前查看的那一天**在格子中央画一个**深绿色椭圆**（长/短轴按格子长宽铺满），所以哪天正好是今天时，椭圆和黑方框可以同时显示、互不冲突；
     - 点某个日期格子，下方换成两段竖排卡片：大标题「**该日创建**」下面是当天创建的任务，大标题「**该日完成**」下面是当天完成的任务；
     - 同一天既创建又完成的任务（例如一次性学习任务）会在两段里各出现一次，这是允许的；
     - 两段用大标题分隔；某一类当天没有时，那一段只写「**该日没有创建的任务**」/「**该日没有完成的任务**」；
     - 选择框下面一行有「**该日创建**」「**该日完成**」两个超链接样式的按钮（点一下直接跳到对应段落），右侧「**更改日期**」回到月历重选；
     - 只有"创建任务 / 完成任务"算改动，**修改日期不算改动**，所以月历的淡绿方块只反映这两类事件。
   - 关掉搜索窗口即退出搜索，不影响主程序。

## 四、提醒 & 后台常驻

- **系统通知**：右下角弹「问候语 + 还剩 N 项」；每天在 **0 / 7 / 9 / 13 / 17 / 20 点**各推一次（0 点即 24 点，共 6 次）。
- **N 的口径**：今天到期的**复习** + 今天到期的**学习计划**合在一起算（如 3 复习 + 2 学习 → "还剩 5 项"）。
- **改文案**：所有提示语在 **`phrases/`** 的 txt 里，一行一句，`#` 注释；任务提示里的 `*` 会被替换成剩余数。保存即生效，无需改代码。
- **托盘常驻**：点窗口 X 不会退出，缩到右下角托盘继续后台提醒；悬停显示任务数，双击打开，右键退出。
- **开机自启**：双击一次 **`开启开机提醒.vbs`**（启动即缩托盘 + 先弹一条今日任务）；**`关闭开机提醒.vbs`** 取消自启并停掉后台。
- **只开一份**：程序有单实例保护，重复双击只会把已有窗口唤起，不会开两个、发两条通知。

### 4.1 提醒是"按触发点调度"的（本版重点优化）

旧版是**每 20 秒轮询一次**看看"到点了吗"；现在改成**用当前时间直接算出下一个提醒时刻，然后一次睡到那一刻**——
一天只在 6 个提醒点被真正"叫醒"，其它时间完全不占 CPU。

**闹钟精度与"迟到不补发"**

| 情形 | 程序行为 |
| --- | --- |
| 整点后 **30 秒内**被叫醒（正常情况） | 正常推送这次通知 |
| 迟到**超过 30 秒**（睡眠/休眠、系统卡顿、长时间没开机） | 这一次**跳过不补发**，立刻按"现在"重排下一个提醒点 |
| 系统从**睡眠 / 休眠恢复** | 收到 Windows 电源广播后**立即重新校准**，不用干等下一个提醒点 |
| **跨天**（0 点、第二天开机、唤醒后） | 自动后移按老规矩照常执行——**即使这次通知被跳过也不会漏做后移** |

> 为什么要"迟到不补发"：如果电脑睡了一夜，醒来时补发一串"7 点、9 点、13 点"的过期通知只会打扰人，
> 所以只保留"当前这个时刻还有意义"的那一条，其余直接跳过并重排。

**省电与兜底**

| 运行方式 | 唤醒频率 |
| --- | --- |
| **有托盘**（正常使用） | 每天约 **6 次**（正好每个提醒点一次），不设额外上限 |
| **无托盘兜底**（托盘不可用，窗口开着） | 最多 **1 小时**唤醒一次做校准，保证跨天/长时间挂机也不跑偏 |

> 托盘图标不可用（极少数系统环境）时程序会自动降级：窗口关掉即真正退出，提醒则每 1 小时自查一次。

## 六、核心数值怎么算

### 6.1 最小结构

```
Series（一条学习内容：2.1 随机变量）
├─ kind      = "review" 复习日程 / "plan" 学习计划(需复习) / "simple_plan" 学习计划(不复习)
├─ learn_date= 首次学习日期 / 应完成日期
├─ done_learn、done_learn_date      （plan / simple_plan 是否已完成学习）
├─ detail    = 任务详情（纯文本，可换行分段；空详情存 ""，界面显示"无"）
└─ reviews   = [Review(第1次), Review(第2次), Review(第3次), Review(第4次)]
    每个 Review: n / date(计划日) / done / done_date(实际完成日)
    (simple_plan 的 reviews 始终为空: 完成学习也不生成复习)
```

### 6.2 关键公式

| 数值 | 算法 |
| --- | --- |
| 复习日期 | 偏移表 `REVIEW_OFFSETS=[1,4,14,28]`：第 i 次复习日 = **学习日期 + OFFSETS[i]** |
| 绿卡完成学习后的复习 | 仅"需复习"类型：以**完成学习当天**为基准生成 完成日 + 1/4/14/28；"不复习"类型不生成 |
| 今日待办 N | `未完成复习且日期 ≤ 今天` 的数量 + `未完成学习计划(需复习/不复习都算)且应完成日期 ≤ 今天` 的数量 |
| 自动后移 | 若某条任务**最早的未完成复习日 < 今天**，把该条**所有未完成复习整体后移** `(今天 − 最早日)` 天，使最早那一次正好落今天；已完成的固定不动。程序**每次启动**、**跨天**、**睡眠唤醒后**各跑一次 |
| 拖欠天数 | 绿卡上 `今天 − 应完成日期`（红色提示"拖欠 N 天"；日期本身程序不改） |
| 今日完成进度 | 已完成 ÷ 待办总数；今天无任何待办 → 显示 100% |
| 还原（取消勾选） | 第 i 次还原会**级联**还原 i~4；并按到期情况安排：当天保持、过期改到今天并整体平移、未来不动 |
| 改期 | 复习行改期：只改该次并把其后**未完成**的按相同天数平移（已完成不动）；任务"学习日期"改期另有规则（见进阶文档） |
| 通知时刻 | 整点 0/7/9/13/17/20；问候语按 6 个时间段（0-7/7-9/9-13/13-17/17-20/20-24）随机 |
| 顶部提示语 | 剩余数**变化时**才重新随机换一句（避免刷新跳字） |

### 6.3 一个完整例子

- 9月5日录「连续型随机变量」，日期选今天 → 复习日程：第1~4次复习计划日 = 9/6、9/9、9/19、10/3。
- 若 9/6 忘了打卡，9/8 才打开程序：自动后移 2 天 → 计划变 9/8、9/11、9/21、10/5（最早未完成的正好落到今天）。
- 另在 9/5 录「9月10日要学 CSAPP 3.10」→ 因日期在未来，生成绿卡（应完成 9/10）。9/10 当天它是绿色"今日到期"并计入"还剩 N 项"；这天你学了它并勾选完成 → 自动生成 4 次复习（9/11、9/14、9/24、10/8）。
- 若录「读完《xxx》」并选**学习计划（不复习）**、日期选今天 → 当天它就是绿色"今日到期"并计入"还剩 N 项"；勾选完成后直接进"完成"清单，**不会产生任何复习**。
- 想找旧任务：点右上角放大镜，输入"CSAPP"回车 → 结果只列任务名，点一下就能打开它的详情/改期。

## 八、桌面苍蝇（可选，默认开着）

**今日还有几张卡没打钩，桌面上就有几只小苍蝇在爬。** 它们是你的"欠账"变成的活物：
压在桌面图标上、被所有窗口盖住（所以浏览器一最大化就看不见它们了），会在任务栏的随机位置
钻出来，鼠标一靠近就飞快逃开，偶尔"爬爬停停"或者突然飞一小段。

> 不想被烦？点右上角 **⚙ 齿轮** 关掉「启用桌面苍蝇」，或者右键托盘图标把「桌面苍蝇」的勾去掉。

### 8.1 一只苍蝇 = 一张今天要打钩的卡片

- 苍蝇数（含卵）**正好等于**「今日待完成」的条数，上限默认 15（可在设置里改 1-30）；
- 你打钩完成一张卡 → 对应的那只飞走，**不是随机消失一只**；
- 数量超过上限时，**超出的立即消失**（苍蝇和卵一起算，不会偷偷变成卵）。

### 8.2 拍苍蝇（要先开苍蝇拍）

- 默认是**纯装饰**：鼠标碰到只会让苍蝇爬走/飞走，点不中它，也绝不会挡住你点任何东西；
- 点 **⚙ 齿轮 → 苍蝇拍 → 开启（跟随光标）**（或托盘右键勾「苍蝇拍」）之后才有杀伤力：
  光标上会跟一把苍蝇拍，**点中苍蝇 = 拍死**，它会淡出，原地留下一个**椭圆的小白点（卵）**；
- 这一刻**任务并没有完成** —— 卵会在设置好的**孵化时间**（默认 1 小时）后原地破壳，同样的位置
  再爬出一只苍蝇继续烦你；如果这 1 小时内你把那张卡打钩了，**对应的卵会自动消失**；
- 拍死的只是"表现层"，**「今日待完成 N 项」这个数字不会变**，数据更不会被改。

### 8.3 设置里能改什么（⚙ 齿轮）

| 分组 | 能改的东西 |
| --- | --- |
| 苍蝇 | 总开关、是否显示卵、数量上限（苍蝇+卵）、苍蝇大小 |
| 苍蝇操作 | 杀死全部苍蝇（全部变成卵）、全部复活、重新出场、清空所有卵 |
| 运动参数 | 爬行速度、飞行速度、逃跑速度（倍率）、**静止时间（直接输入秒数）**、逃跑触发半径、振翅频率 |
| 苍蝇拍 | 开关、拍打命中半径、挥拍动画、拍子大小、是否只在桌面可见时才显示拍子 |
| 层级/性能/隐私 | 只在桌面级 / 最上层、被遮挡时暂停、锁屏时暂停、电池降帧、**截屏录屏隐身**、出场方式（任务栏随机 / 托盘区 / 混合） |
| 孵化时间 | **时 + 分** 两个输入框（**分钟必须是 0-59**，输错了输入框变红并提示，不会偷偷改成别的值） |

- 设置**改完即时生效**，没有"确定/取消"；
- 设置存在 `appdata/prefs.json`，和任务存档 `data.json` 完全分开；
- 想回复原样：设置窗左下角「恢复默认设置」。

### 8.4 卵活得过重启

卵带着"什么时候破壳"一起写进 `appdata/flies.json`，关掉程序（甚至重启电脑）再打开，
倒计时接着算，到点的会自己爬出来。
